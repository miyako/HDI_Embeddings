Set up your AI provider
This project is preconfigured for OpenAI: the provider is declared and the "Embed" model alias uses text-embedding-3-large. You only need to add your API key:
1. Click Open 4D AI Settings below.
2. On the Providers tab, enter your API Key, then click Test connection.
3. Click OK to save, then return to this window.

Using another provider? Change the Base URL on the Providers tab (no API key is needed for a local Ollama server), then select an embedding model for the Embed alias on the Model Aliases tab. Then click Generate all vectors on the Generate Embeddings tab: vectors computed with different models cannot be compared.
