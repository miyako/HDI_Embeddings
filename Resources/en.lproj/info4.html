Which button should I use?
• Generate all vectors – recomputes the vector of every student. Use it whenever you change the model or the phrase template: vectors computed with different models cannot be compared.
• Generate invalid vectors – only processes students whose vector is missing or flagged as dirty (see the Update Records page). This is the one to use day to day: the AI provider is only called for what actually changed.

The first time you run this demo, no vector exists yet: both buttons compute all of them.

What happens behind the scenes
For each student to process, the component:
1. Renders a text phrase using the configured template
2. Sends the text to the embeddings API (in batches)
3. Stores the resulting 4D.Vector in the student_vector field

The result area shows how many entities were updated, tokens consumed, and any errors. Some local providers such as Ollama do not report token usage, so this counter may stay at 0.
