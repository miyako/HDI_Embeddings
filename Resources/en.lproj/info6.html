Try it:
1. Type a text in the Search field, for example "AI research", "network security" or "loves databases".
2. Click Search: the most similar students are listed, best match first.
3. Uncheck Include dirty vectors and search again to exclude students whose vector is out of date (Dirty column = Yes).
4. Change the Threshold and search again: a higher value keeps only the closest students, a lower value returns more results. The right value depends on the model.
5. Click Clear search to list all students again.

What happens behind the scenes
1. The Embedding Studio component embeds your query text with the same model alias as the stored vectors.
2. 4D runs a native vector similarity query on the student_vector field, using the cosine similarity.
3. Only students whose similarity is above the threshold are kept, best match first.

Because the search is semantic rather than keyword-based, you can use natural language, topics or descriptions, not just exact field values.
