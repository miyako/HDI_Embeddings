Try it:
1. Select a student in the list and change a field used in the phrase (e.g. the biography).
2. Click Save: the row turns red and the Dirty column shows Yes.
3. Go back to the Generate Embeddings tab and click Generate invalid vectors: only this student is recomputed.
4. Come back here: the row is no longer red.

Why? The embedding definition has Auto-invalidate on save enabled and the Students table has a student_vector_dirty field. Saving the entity does not call the AI provider: the component only flags the vector as dirty, so the vector is recomputed later, in batch.

On the Search Embeddings tab, uncheck Include dirty vectors to exclude students whose vector is out of date.
