1. Create the vector field
In this demo, the Students table already has a student_vector field (Object type, 4D.Vector class) to store the embeddings.

It also has a Boolean student_vector_dirty field (vector name + _dirty). When a student changes, the component uses it to flag the vector as out of date instead of clearing it, so the student can still be found until the vector is recomputed.


2. Configure the vector
In Design > Embedding Studio, select the student_vector line and define:
• Descriptive Phrase: the text sent to the model. Fields between braces are replaced by their values, e.g.:
Student {firstName} {lastName}, studying {program}. {bio}
• Model: the model alias defined on the Configure AI settings tab (Embed).
• Auto-invalidate on save: flags the vector as dirty when a student is saved (see the Update Records tab).

The definition is saved in Settings/embeddings.json.
